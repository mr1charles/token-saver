token-saver

A Claude Code skill that stops sessions from burning tokens.

Why sessions get expensive

Every turn pays for the fixed context (system prompt, tool names, connector instructions, skill list, memory files) plus the whole conversation again. The history part grows each turn and is usually the bigger bill.

Install

git clone https://github.com/mr1charles/token-saver
cp -r token-saver/skills/token-saver ~/.claude/skills/

Then ask Claude "audit my token use", or run python3 ~/.claude/skills/token-saver/scripts/audit.py.

The rules

  1. One task per session; /clear at ~150k tokens.
  2. /compact after long tool-heavy stretches.
  3. Read small: grep, head, tail, line ranges.
  4. Images at 900 px wide or less.
  5. Batch independent tool calls.
  6. Skip subagents unless clearly worth it.
  7. Run long jobs in the background; read the last lines only.
  8. Short answers, no recap.
  9. Keep instruction files under ~40 lines.

Cut fixed context

  • Turn off unused plugins in settings.json (enabledPlugins).
  • Deny unused connectors with permissions.deny (mcp__claude_ai_Name).
  • Verify with /context.

Token numbers from the audit script are rough (about 4 characters per token). Source on GitHub
